Kinesiology Portfolio | Chadwick Randall

Overview

This portfolio was developed as the final project for KNES 381 - Computer Applications in Kinesiology. This demonstrates
both technical and analytical understanding as well as skills as a Kinesiology student. The website displays coursework 
that focused on analysis of athlete data, visualization, and use of programming tools such as Python, Excel, and HTML.

The goal with this project was to present my understanding of course required concepts and my ability to apply computer 
applications in a real world Kinesiology setting.


Live website

Acts as a portfolio of the skills and tools used across the course.

Tools and Systems used

- Python for data processing, analysis, and visualization
- Excel for formula based analysis and dynamic capability for charting
- HTML/CSS for website structure and styles
- GitHub for version control and projecct hosting
- Scratch for learning and displying logic based programming

Individual Components

Athlete Performance Notebook (Python)
